# Tutor Landing Starter

Готовий статичний односторінковий сайт для приватного репетитора. Перша конфігурація — українськомовна викладачка англійської, але контент і тема відокремлені від компонентів.

## Запуск

```bash
npm install
npm run dev
```

Збірка й перевірки:

```bash
npm run check
npm run format:check
npm run build
```

## Персоналізація

1. Відредагуйте `src/config/site.ts`: ім’я, опис, контакти, напрями, формати, ціни та FAQ.
2. Замініть `https://t.me/your_username`, `hello@example.com` і значення `ХХХ ₴` перед публікацією.
3. Додайте дозволений портрет у `public/images/` та вкажіть шлях у `tutor.photo`. Не додавайте клієнтські фото без явної згоди.
4. Додавайте лише справжні підтверджені відгуки до `testimonials`, потім встановіть `sections.testimonials: true`.
5. Секції `facts`, `pricing` і `testimonials` вмикаються у властивості `sections`. Для нового опціонального блока додайте аналогічний прапорець у тип і конфігурацію.
6. Основні кольори та розміри задаються CSS-змінними на початку `src/styles/global.css`.
7. Оновіть `site` в `astro.config.mjs`, URL sitemap у `public/robots.txt`, SEO-тексти й Open Graph зображення.
8. Перевірте та адаптуйте базову політику конфіденційності до фактичних інструментів і законодавчих вимог.

## Розгортання

Виконайте `npm run build`. Готовий статичний сайт з’явиться в `dist/` і може бути розгорнутий на Netlify, Cloudflare Pages, GitHub Pages або будь-якому статичному хостингу. Команда збірки — `npm run build`, каталог публікації — `dist`.

## Межі шаблону

У проєкті немає бекенду, CMS, аналітики, рекламних пікселів, онлайн-оплати, CRM, особистого кабінету чи власного календаря. Запис відбувається через пряме посилання на месенджер.
